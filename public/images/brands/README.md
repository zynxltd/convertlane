# Partner brand logos (homepage marquee)

Add SVG or PNG logos here, then set `logo` in `config/brand.php` → `partner_brands`:

```php
['name' => 'LanePay', 'slug' => 'lanepay', 'logo' => '/images/brands/lanepay.svg'],
```

Recommended: horizontal logo, max height ~32px, transparent background.

Until logos exist, the site shows typographic wordmarks.
