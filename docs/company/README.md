## Hard rules (entire company)

1. **No Affise tracking links** until DD status = `approved`.
2. **No advertiser traffic** without prepay or approved credit line.
3. **Every offer** has a signed IO (or e-sign equivalent) before caps are opened.
4. **Compliance can veto** any partner or traffic type — no commercial override.
5. **All status changes** logged in `/compliance` with notes on reject/hold.
