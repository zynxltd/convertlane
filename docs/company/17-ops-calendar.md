# Operations calendar (team of 5)

Recurring tasks so nothing relies on memory. Adjust dates to your timezone.

---

## Daily (15 min each role)

| Role | Task |
|------|------|
| **Compliance** | Check new applications; triage compliance inbox |
| **Publisher Lead** | Reply publisher emails; check cap alerts |
| **Advertiser Lead** | Reply advertiser emails; cap vs spend |
| **Finance & Ops** | Affise cap alerts; prepay balances |
| **MD** | Only P1 escalations + pipeline skim |

---

## Monday (30 min stand-up)

Agenda: applications in flight · offers launching · fraud flags · cash this week.

Output: 3 actions per person written down.

---

## Wednesday (20 min)

| Role | Task |
|------|------|
| Compliance + AMs | Fraud / quality review Affise flags |
| Finance | Advertiser ledger vs caps |

---

## Friday (20 min)

| Role | Task |
|------|------|
| Publisher Lead | Probation publishers (first 30 days) |
| Advertiser Lead | IO renewals / expiries next 30 days |
| Finance | Payout preview if month-end approaching |

---

## Monthly

| When | Task | Owner |
|------|------|-------|
| 1st–3rd | Export Affise prior month | Finance |
| 3rd–7th | Reconcile advertisers | Finance + AMs |
| 5th | Compliance holds cleared for payout | Compliance |
| 7th–10th | Wise payout batch prepared | Finance |
| **15th** | **Publisher payouts sent** | Finance |
| 20th | Advertiser invoices (credit accounts) | Finance |
| Last Friday | Cap review all live offers | AMs |
| Quarterly | DD refresh sample / triggers | Compliance |
