# Offer launch checklist

**Owner:** Finance & Operations · Use for every new or materially changed offer.

**IO reference:** CL-________ · **Offer name:** ________________ · **Date:** __________

---

## Before setup (gates)

- [ ] Advertiser status = `approved`  
- [ ] Signed [advertiser agreement](06-advertiser-agreement.md) on file  
- [ ] Signed IO matches commercial terms agreed  
- [ ] Compliance cleared vertical/geo ([03-kyc-kyb-policy.md](03-kyc-kyb-policy.md))  
- [ ] Prepay received **or** credit line covers cap ([09-advertiser-billing-policy.md](09-advertiser-billing-policy.md))  
- [ ] Landing URLs live and match IO  
- [ ] Postback / validation rules documented  

---

## Affise configuration

- [ ] Offer created — **Affise offer ID:** ______  
- [ ] Correct payout model (CPA / CPL / CPS / hybrid)  
- [ ] Payout amount matches IO  
- [ ] Geos restricted per IO  
- [ ] Caps set (daily / monthly): ______  
- [ ] Cookie window: ______ days  
- [ ] Allowed traffic types noted in offer description  
- [ ] Prohibited traffic noted  
- [ ] Test click + test conversion completed  
- [ ] Postback received on test (if applicable)  

---

## Publisher assignment

- [ ] Only `approved` publishers added  
- [ ] Each publisher has signed IO for this offer  
- [ ] Publisher Lead confirms traffic fit  
- [ ] Probation caps for new publishers if needed  

---

## Creatives

- [ ] Default tracking link tested  
- [ ] Approved banners/landers linked in offer notes  
- [ ] Pre-lander URLs archived  

---

## Finance & reporting

- [ ] Offer ID added to advertiser ledger / prepay allocation  
- [ ] Forecast sheet updated  
- [ ] Listed on public `/offers` page if marketing approved (optional)
